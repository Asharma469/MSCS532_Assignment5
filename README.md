# MSCS532_Assignment5
Quick sort Analyysis

Has QuickSort implementations choosing the pivot at:
- first element
- middle element
- random element

## Requirements

- Python 3
- No third-party packages are required.

## Run the benchmark

From the repository directory, run:

```bash
python main.py
```

UnComment line 130 on `main.py` to print 4 different arrays of length 100, sorted by all 3 quick sorts. It prints 12 sorted arrays.
